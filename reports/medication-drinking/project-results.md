# 복약 행동 영상 라벨링 결과 보고서

사용본 집계 기준일: 2026-11-25 (KST)

복약·물마시기와 이와 비슷한 행동을 영상에서 구분하기 위한 라벨을 설계하고 작성했다. 이 보고서는 프로젝트에서 사용하기로 고정한 라벨의 형식별 수량, 검수 범위와 관찰 한계를 정리한다. 라벨링 절차는 [데이터 라벨링 방법](../../docs/data-methods.md), 항목의 뜻은 [라벨·분석 항목 안내](../../docs/analysis-label-guide.md)에 있다.

## 1. 요약

- 프로젝트 사용본은 **474개**다. 영상별로 마지막에 저장한 revision을 하나씩 고정했다. 474는 목록의 행 수이면서 서로 다른 기록 원본 SHA-256의 수다.
- **시점 라벨 389개를 작성하고 전수 검수를 완료했다.** 검수 완료의 근거는 사용자의 직접 확인이다.
- 공통 형식 85개(v0.2 64개, v0.1 21개)도 사용자 검수를 완료했다. v0.2는 클립 단위로 검수했다.

## 2. 형식별 사용본과 검수 범위

| 라벨 형식 | 사용본 | 기록 내용 | 사용자 검수 |
| --- | ---: | --- | --- |
| 시점 라벨 `medication-event-spot-label-v1` | 389 | 행동 종류, 재생 경과시간 기준 시작·종료, 경계의 확실성, 영상 판단 | 전수 검수 완료 389 |
| 공통 v0.2 `onc110-behavior-annotation-v0.2` | 64 | 분석 8항목, 행동 구간과 질문별 답변·근거, 대안 행동, 클립 판단 | 클립 검수 완료 64 |
| 공통 v0.1 `onc110-video-label-v0.1` | 21 | 분석 8항목, 행동 후보 구간과 질문별 답변·근거 | 검수 완료 21 |

- **시점 라벨**: 사용자가 389개 전수를 직접 확인했다. 이 확인은 원본 작업공간의 작업 기록에 남겼다. 영상별 검수 일시는 기록하지 않았다. 라벨 파일의 `review` 필드에는 저장 당시의 값이 그대로 남아 있으며, 검수 결과를 반영하려고 고친 적이 없다. 필드 값을 읽는 법은 [시점 라벨 형식](../../schemas/event-spot.md#상태와-사용-범위)에 있다.
- **공통 v0.2**: revision의 `human_review`에 검수자, 서버 기록 시각과 확인한 프레임 범위가 남아 있다. 검수 범위는 클립(`CLIP`)이다.
- **공통 v0.1**: 사용자가 21개의 검수를 완료했다. 검수 완료의 근거는 사용자의 직접 확인이며 원본 작업공간의 작업 기록에 남겼다. 라벨 파일의 검수 필드(`coverage`, `review`)는 저장 당시 값을 유지한다.

## 3. 라벨 형식의 변화와 확대 과정

| 순서 | 형식 | 사용본 | 바뀐 점 |
| --- | --- | ---: | --- |
| 1 | 공통 v0.1 | 21 | 분석 8항목과 라벨을 같은 revision에 저장했다. 준비·복약 후보·음용 구간, 질문별 답변과 근거를 기록했다. |
| 2 | 공통 v0.2 | 64 | 같은 저장 구조에서 복약 후보의 판단 기준을 넓히고, 대안 행동과 판단 범위를 함께 기록했다. |
| 3 | 시점 라벨 | 389 | 행동 종류·구간·경계 확실성 중심으로 항목을 줄이고, 별도로 선정한 영상 묶음에 적용했다. |

### 3.1 공통 v0.1

한 revision에 영상 전반의 분석 8항목과 행동 라벨을 함께 저장했다. 라벨은 준비(E01), 복약 후보(E02), 음용(E03)의 구간을 표시하고 구간마다 두 질문에 답과 근거 프레임을 남긴다. 복약 후보의 질문은 **물체가 약으로 식별되는가**와 **입안 전달이 보이는가**였다. 일반 영상에서는 작은 알약이나 손안의 물체를 식별하기 어려워, 이 두 질문은 판단 불가로 남는 경우가 많았다.

### 3.2 공통 v0.2

공통 저장 구조와 분석 8항목은 그대로 두고 행동 판단 기준을 확장했다. 복약 후보에는 **손의 입 접근**과 **섭취형 동작**을 기록한다. 같은 동작이 음용 등 다른 행동으로 설명되는지(대안 행동)와 판단을 적용한 범위도 함께 다룬다. 확인된 복약형 동작을 실제 약 성분이나 삼킴의 확인으로 보지 않는다.

v0.2 최신본 64개 가운데 **54개**는 같은 영상의 이전 v0.1 revision이 있다. 이 영상들도 새 기준으로 다시 관찰해 분석과 라벨을 새로 작성했다. v0.1 답변을 새 의미로 옮겨 적지 않았고, 이전 기록은 같은 영상의 이력으로 보존했다. 나머지 **10개**는 v0.2 작성 때 새로 등록한 음수 영상이다.

### 3.3 시점 라벨

공통 형식의 행동 종류와 구간 기록 방식에서 출발해 양식을 줄였다. 시점 라벨에는 행동 종류(준비·복약형·음용), 재생 경과시간 기준 시작·종료, 경계의 확실성을 기록한다. 상세 분석 8항목, 질문별 답변, 행동 간 관계는 필수 항목에서 뺐다.

별도로 선정한 **40개**에서 시작해 **349개**를 추가했다. 추가분은 행동별로 고정한 목록(복약 119·물마시기 124·기타 106)이다. 마감 목록에서 공통 형식 85개와 시점 라벨 389개의 기록 원본 SHA-256 교집합은 **0건**이다. 시점 라벨은 기존 공통 라벨을 바꿔 만든 것이 아니라 간소화한 양식을 별도 영상 묶음에 적용한 결과다.

## 4. 기록된 라벨 분포

아래의 선정 분류는 원본 폴더·파일명의 행동 코드에서 온 목록 정보다. 행동의 정답으로 쓰지 않으며, 라벨과 나란히 놓아 분포를 읽기 위해서만 사용했다.

### 4.1 시점 라벨 389개

| 선정 분류 | 영상 | 기록한 행동 구간 | 영상 판단 |
| --- | ---: | --- | --- |
| 복약 (A003) | 134 | 준비 158 (134개 영상) · 복약형 134 (133개 영상) | 확인 132 · 불확실 2 |
| 물마시기 (A004) | 141 | 음용 153 (141개 영상) | 불확실 141 |
| 기타 46종 | 114 | 없음 | 불확실 114 |
| 합계 | 389 | 445 | 확인 132 · 불확실 257 |

- 영상 판단은 **보이는 복약형 동작**에 대한 판단이다. 부재를 확정하려면 영상 전체를 그만큼 촘촘히 관찰해야 하므로, 복약형 동작이 기록되지 않은 영상은 불확실로 남겼다.
- 행동 구간 수는 종류별 행동 횟수로 영상마다 함께 기록했다.
- 라벨 파일에 저장된 관찰 방식은 표본 관찰 208개, 표본 관찰에 경계 주변 원본 연속 프레임을 더한 경우 177개, 원본 전 프레임 관찰 4개다. 검수에서 확인한 경계 범위는 이 저장 값에 반영하지 않았다([7.1절](#71-표본-관찰의-보완)).

### 4.2 공통 v0.2 64개

| 선정 분류 | 영상 | 클립 판단 |
| --- | ---: | --- |
| 복약 (A003) | 32 | 확인 28 · 불확실 4 |
| 물마시기 (A004) | 32 | 복약 미관찰 26 · 불확실 6 |

기록한 행동 구간은 준비(E01) 31개, 복약 후보(E02) 50개, 음용(E03) 33개다. 경계는 대략 112개, 미확정 2개다. 클립 판단은 해당 클립 안에서의 판단이며 전체 복약 과정의 성공 여부를 뜻하지 않는다.

### 4.3 공통 v0.1 21개

선정 분류는 복약 13개와 기타 8개다. 준비(E01) 12개와 복약 후보(E02) 15개 구간을 기록했다. 복약 후보의 약 식별 답은 판단 불가 13·아니오 2, 입안 전달 답은 판단 불가 14·예 1이다. 준비 구간의 취급 답은 예 10·판단 불가 2, 내용물 꺼냄 답은 모두 판단 불가다.

## 5. 원본 확인 범위

원본 영상의 SHA-256은 기존 원장에 기록된 값이다. 마감 때 영상 바이트를 다시 해시하지 않았다.

| 대상 | 확인한 범위 |
| --- | --- |
| 시점 라벨 338개 | 복원된 로컬 분류본에서 원본 대응 목록의 경로와 파일 크기가 일치했다. |
| 시점 라벨 51개 | 로컬 복원에서 제외된 ETRI RGB 원본(로봇환경 48·리빙랩 3)이다. 기록된 상대 위치에서 파일을 찾지 못했다. 원본 상대경로와 백업 ZIP 이름 후보를 로컬 목록에 남겼고, ZIP 내부 대조·내려받기·해시 확인은 하지 않았다. |
| 공통 형식 85개 | 로컬 영상 사본과 프레임 대응표(frame-map)가 있다. 기존 원장에 크기가 기재된 75개는 크기가 일치했고, 10개는 크기 기재가 없다. |

두 형식 사이에서 ID, 기록 원본 SHA-256, 원본 상대 계보가 직접 일치한 경우는 0건이다. 바이트가 달라진 변환본이나 기록에 없는 별칭·파생본의 중복 여부는 확인하지 않았다.

## 6. 개발 노출

- **시점 라벨**: 1개는 개발 전용 라벨로 작성해 개발 노출이 있다. 388개는 알려진 개발 노출이 없다(`NOT_KNOWN_EXPOSED`). 이 값은 확인된 미노출을 뜻하지 않는다.
- **공통 v0.2**: 64개 모두 고정 발행한 개발용 인수본(4·20·40개)에 포함돼 개발에 노출됐다.
- **공통 v0.1**: 1개가 개발용 영상 목록에 포함됐고, 20개는 노출 기록이 없다.
- 개발용 고정 영상 목록 156개와 비교하면 기록 원본 SHA-256이 겹치는 것은 시점 라벨 0개, 공통 형식 5개다.
- 공식 학습·검증·시험 분할과 모델 성능 평가는 이 작업 범위에서 수행하지 않았다.

## 7. 관찰 한계와 보완

### 7.1 표본 관찰의 보완

시점 라벨은 처음에 영상 전체를 약 1초 간격 표본으로 훑어 작성했다. 이 방식에서는 표본 사이의 짧은 동작을 놓치거나 경계가 표본 간격만큼 어긋날 수 있다. 이 한계는 검수·수정 과정에서 보완했다.

- **경계 재확인과 수정.** 복약·물마시기 영상 전체의 행동 경계를 다시 확인했다. 경계 수정 작업에서는 250 ms 간격 원본 표본, 후보와 앞뒤 1초의 100 ms 간격 표본, 시작·끝 주변 원본 연속 프레임을 사용해 손이나 용기의 이동·회수와 실제 취급·입으로 가져가는 동작을 구분했고, 고친 구간은 새 revision으로 저장했다.
- **전수 검수.** 사용자가 389개 전수를 검수하면서 행동 구간·경계와 구간 수를 함께 확인했다.

### 7.2 남은 한계

- 가림, 작은 화면 크기, 영상 시작이나 끝에서 잘린 동작, 비슷한 동작(얼굴 만지기, 음식 먹기 등)은 구간과 경계 판단을 어렵게 한다. 이런 경계는 대략(`APPROXIMATE`) 또는 미확정(`UNRESOLVED`)으로 남겼다.
- 복약형 동작이나 섭취형 동작을 관찰했다고 해서 약의 종류, 실제 삼킴, 처방 일치까지 확인한 것은 아니다. 음용 동작도 액체의 종류나 양을 확인하지 않는다.
- 클립 판단은 촬영된 범위 안의 판단이다. 촬영 범위 밖의 행동이나 전체 복약 과정의 성공 여부로 넓혀 해석하지 않는다.
- 선정 분류(행동 코드)는 목록 정보이며 라벨 결과와 다를 수 있다.

## 8. 근거와 자료 위치

- 사용본 목록과 집계의 근거는 원본 작업공간의 로컬 마감 목록이다. 목록에는 영상별로 선택한 revision의 상대경로와 파일 SHA-256이 고정돼 있다.
- 실제 영상, 라벨 전문, 원본 대응 목록, 검수 원장은 공개 저장소에 포함하지 않는다. 형식은 [시점 라벨 형식](../../schemas/event-spot.md)과 [공통 저장 규약](../../schemas/README.md), 가상 자료는 [합성 예제](../../examples/README.md)에서 볼 수 있다.
- 2026-10-19의 46건 보고서와 그 이전 판은 당시의 v0.1 질문과 다른 분모로 집계했다. 이 보고서의 수치와 직접 비교하지 않으며 원본 작업공간에 보존한다.
